ESP8266 IoT

Cloudflare DDNS, signed OTA and local IoT on an ESP-01. Version ….

This browser cannot flash over USB (Web Serial). Use Chrome or Edge on a computer. Flashing only works over HTTPS.

Before you start

  • A 1 MB ESP-01 or ESP-01S and a 3.3 V USB-serial adapter.
  • Chrome or Edge on a computer.

Step by step

  1. Connect GPIO0 to GND, then plug the adapter into USB. The ESP-01 does not enter flashing mode on its own.
  2. Click Install and pick the adapter's serial port.
  3. On a first install, accept erasing the device. To update a device that is already set up, do not erase: the configuration is kept.
  4. When it finishes, unplug the adapter, release GPIO0 and plug it in again. The installer's reset button does not work on the ESP-01.
  5. Click Read the device password and pick the port again: each device has its own, drawn on first boot.
  6. Join the ESP_Config network with that password, open http://192.168.4.1, enter your Wi-Fi and set the panel password.

With the device already flashed, powered without GPIO0 on GND. The password also shows on the panel, under Status.

Erasing the device also erases its configuration (Wi-Fi, Cloudflare, ntfy, IoT).

Once installed, the firmware updates itself through signed OTA. Documentation: README.
